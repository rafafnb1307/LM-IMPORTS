⚠️ O Windows Defender pode alertar — é completamente normal!

O AutoClean acessa pastas do sistema para realizar a limpeza, e por isso o Windows Defender pode exibir um aviso de segurança ao executar o arquivo. O app é 100% seguro — ele apenas remove arquivos temporários, cache e logs. O alerta ocorre porque o executável não possui assinatura digital paga (certificado de desenvolvedor), não porque seja perigoso.

Para prosseguir: clique em "Mais informações" → "Executar assim mesmo".
